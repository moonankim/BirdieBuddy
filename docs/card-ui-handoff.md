# 카드 목록·상세·강화 UI 인계

**기준일:** 2026-11-12 · **담당:** 현호P

## 이번 변경의 범위

기획·아키텍처와 [최신 카드 명세](./card-spec.md)를 기준으로 카드 화면의 **UI 목업**을 보완했습니다. 사용자가 이번 단계의 API 연결을 명시적으로 제외했습니다. 로그인 방식과 관계없이 카드 장수·수집 현황·강화 비용은 예시이며 실제 소유 정보가 아닙니다. DB·RLS·SDK·발급 확률·원격 배포는 변경하지 않았습니다.

카드 이미지는 사용자 요청대로 공통 디폴트 실루엣을 사용합니다. [CDN manifest](./assets/card-images.json)에서는 선수 식별자와 유형만 재사용하고 이미지를 요청하지 않습니다. 선수 12개를 DB UUID·템플릿 12개로 확정하거나 기존 시드와 순서대로 연결하지 않습니다.

## 화면과 진입 계약

| 경로 | 구현 내용 |
| --- | --- |
| `/collection` | 미보유 포함 템플릿 목록·등급별 수량·수집 현황 |
| `/collection/owned` | 양수 수량의 템플릿×등급 조합·보유 합계 |
| `/collection?tab=owned` | 기존 링크 호환용. `/collection/owned`로 이동 |
| `/collection/[cardId]?grade=basic&from=owned` | 선택 등급의 상세·장수·인증 근거가 있을 때 배지 표시 |
| `/collection/upgrade?cardId=c2&grade=basic&from=owned` | 디폴트 카드로 소모·획득·잔여 확인과 결과 미리보기 |

`grade`는 basic/rare/legend만 허용합니다. 상세에서 생략하면 목업의 최고 보유 등급, 미보유는 basic을 선택합니다. 명시된 잘못된 등급이나 카드 ID는 다른 카드로 대체하지 않고 카드 없음 화면을 표시합니다. `from=owned`의 복귀는 `/collection/owned`로 고정하며 외부 주소를 받지 않습니다. 경로의 cardId는 현재 목업 식별자이며 서버 UUID가 아닙니다.

## 목록의 표시 규칙

- 컬렉션은 미보유도 포함합니다. 등급 선택은 그 등급을 표시 대상으로 바꾸며 미보유 템플릿을 삭제하지 않습니다. 각 템플릿에서 세 등급 수량과 상세 진입을 제공합니다.
- 보유 목록은 수량이 1장 이상인 조합만 표시합니다. 한 선수의 BASIC과 RARE는 별개 항목입니다.
- 선수·유형·등급 필터와 등급 높은 순(기본)·장수 많은 순 정렬을 제공합니다. 컬렉션의 장수 정렬은 선택 등급의 수량, 등급 전체 선택 시 합계로 계산합니다.
- 수집한 종류는 양수 수량이 있는 템플릿 수, 전체 종류는 목록 길이입니다. 보유 합계는 등급별 수량을 합산합니다. 고정 3/12·이름 없는 미보유 카드 추가는 제거했습니다.
- 강화 비용은 `previewUpgradeCost=10`이라는 시안 값입니다. 충분한 수량과 다음 등급이 있는 조합만 목록·상세에서 강화 미리보기로 연결합니다.
- 등록 없음·전체 미보유·필터 결과 없음·로딩·조회 오류/재시도 표시를 분리했습니다. 현재 `CardCollection`의 `status`·`onRetry`는 표시 인수용이며 실제 요청·인위적 지연/오류는 없습니다.

## 강화 미리보기와 실제 강화의 경계

체험 가능한 예시는 c2 BASIC 11장입니다. 수량 확인 체크 후 결과를 표시하며 10장 사용·RARE 1장 획득·BASIC 1장 잔여를 계산합니다. 결과는 컴포넌트 안의 일시적 상태이며 목업 원본·실제 장수·인증·입장 자격을 변경하지 않습니다. 복귀·새로고침 시 초기화됩니다. 최고 등급·부족 수량·잘못된 카드 선택을 차단하고 결과 제목으로 포커스를 이동합니다.

시간 지연·화려한 연출·API 요청·멱등 ID·실패 복구·계정별 결과 저장은 구현하지 않았습니다. 실제 강화가 완료됐다고 보고하거나 결과를 실제 소유 정보로 반영하면 안 됩니다.

## 검증과 남은 제약

UI 테스트는 목록 표시 단위·필터/정렬·수집 계산·0장 제외·등급별 진입·카드 없음·강화 확인/결과·복귀 경로를 검증합니다. 실행 명령은 `npm run test:ui`, `npm run build`, `npm run lint`, `npm run typecheck:ui`이며 타입 검사는 빌드와 동시에 실행하지 않습니다.

브라우저·미리보기는 열지 않았습니다. 실제 로그인 사용자의 카드 API 연동, 전체 화면 육안 검수, CDN 렌더링과 원격 배포는 미검증입니다. 커밋 후에도 push·main 통합 여부는 별도로 확인합니다.
