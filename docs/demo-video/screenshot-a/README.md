## 어떻게 찍었나

- **모드**: 목 모드(`NEXT_PUBLIC_DATA_MODE=mock`) 프로덕션 빌드(`next build --webpack` → `next start`)를 로컬에서 띄우고 Playwright(Chrome)로 찍었습니다.
- **크기**: 모바일 390×844, 2배율이라 PNG는 780×1688입니다.
- **A03 녹화**: `A03-draw-reveal.webm`은 390×844 실제 크기로 녹화했습니다. 녹화는 2배율을 담지 못합니다.
- **화면 이어 찍기**: A06부터 C02까지는 한 브라우저 안에서 계정만 바꿔 가며 이어 찍었습니다. 목 데이터가 브라우저 메모리에만 있어서 새로 불러오면 사라지기 때문입니다.
- **앱 코드**: 바꾸지 않았습니다. 아래 "화면에서 바꾼 것"은 찍는 순간 브라우저 화면에만 적용했습니다.
- **목 모드로 할 수 없는 것**: 목 모드에서는 AI가 가짜로 동작합니다. 그래서 A07 수정 제안과 B05 요약 문장은 서비스와 같은 AI 모듈(`supabase/functions/_shared/ai/`)을 로컬에서 실제 API로 1회씩 불러 만든 결과를 넣었습니다.
