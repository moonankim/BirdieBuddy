## 이 문서를 쓰는 방법

- **앱 화면 컷**: 스크린샷 자리를 `shots/<장면>-이름.png`로 정해 두었습니다. 같은 이름으로 `docs/demo-video/shots/`에 넣습니다. 움직임이 필요한 곳(A03 카드 공개)은 화면 녹화 `shots/<장면>-이름.mp4`입니다.
- **AI 영상 컷**: 영상 자리를 `footage/<장면>-이름.mp4`로 정해 두었습니다. [AI 영상 프롬프트](#ai-영상-프롬프트)로 생성해서 같은 이름으로 `docs/demo-video/footage/`에 넣습니다.
- 맨 아래 [작업 체크리스트](#작업-체크리스트)가 실제 작업 목록입니다.
- 영상의 인플루언서는 **김홍차(G투어)** 한 명입니다(가정 5).

## 화면 배치와 자막 규칙

**AI 영상 컷**: 16:9 전체 화면, 자막은 하단 가운데.

**앱 화면 컷**: 가운데에 폰 프레임(390px 화면), 왼쪽에 장면 제목, 오른쪽에 자막. 자막이 폰 화면을 가리지 않게 합니다.

```
┌──────────────────────────────────────────────────────────┐
│   [AI ②]               ┌────────┐                        │
│   메시지 안전 필터      │  폰    │      보내기 전에        │
│   ← 장면 제목           │  화면   │      AI가 먼저 검사    │
│                        │ 390px  │      ← 자막            │
│                        └────────┘                        │
└──────────────────────────────────────────────────────────┘
```

**줌 전환(AI 영상 → 앱 화면)**: AI 영상이 폰 화면을 크게 보여 주는 클로즈업으로 끝나게 생성하고(프롬프트에 포함), 편집에서 폰 화면 쪽으로 조금 더 확대(1초) → 폰 프레임 앱 화면으로 크로스페이드합니다. AI 영상 속 폰 화면은 글자가 뭉개진 가짜 화면이 나오기 쉬우므로, 화면을 밝게 빛나는 빈 화면으로 생성해 전환 직전 하얗게 번지는 느낌으로 넘깁니다. 영상 생성 결과는 보통 1080p라 편집에서 많이 확대하면 흐려지니, 확대는 조금만 합니다.

**자막 규칙**:
- 한 줄 20자 안팎, 한 번에 최대 2줄, 한 번에 한 문장.
- 표시 시간: 공백을 뺀 글자 수 ÷ 5 + 1초, 최소 2초.
- 앱 화면에 이미 크게 나온 문구는 자막으로 반복하지 않습니다.
- AI 기능 장면은 장면 제목에 `AI ①~⑤`를 붙입니다.

**표현 원칙**: 카드 등급은 BASIC·RARE·LEGEND로만 씁니다. 강화는 목업이므로 "카드가 실제로 차감된다"고 쓰지 않습니다. 보유 배지의 구체적 기준은 미확정이라 쓰지 않습니다. 목업 화면의 "목업" 안내와 "(예시)" 문구는 편집에서 가리거나 잘라 냅니다.

## AI 영상 프롬프트

Claude Code는 영상을 직접 생성하지 못하므로, 아래 프롬프트를 영상 생성 도구에 넣어 만듭니다. 대부분의 도구는 영어 프롬프트가 더 잘 통해서 영어로 적었습니다.

### 만드는 순서

1. **기준 이미지 먼저**: 팬 인물 이미지 1장을 이미지 생성 도구로 만들어 고정합니다(아래 "팬 기준 이미지"). 인플루언서는 카드에 쓴 가상 인물 사진을 씁니다.
2. **이미지→영상**: 장면마다 기준 이미지를 참조로 넣고 아래 프롬프트로 5~8초 클립을 만듭니다. 장면마다 3~4개를 뽑아 가장 자연스러운 것을 고릅니다.
3. **검수**: 손가락 수, 클럽 모양, 스윙 자세, 폰 화면의 이상한 글자를 확인합니다. 카드 사진 만들 때도 손·클럽·자세 문제가 반복해서 나왔으니 원본 크기로 봅니다.

### 피해야 할 것

- **스윙 클로즈업**: AI 영상은 골프 스윙 동작(클럽 궤적, 손목)을 자주 틀리게 만듭니다. A01은 뒤에서 넓게 잡고, 임팩트 순간보다 피니시와 스크린 속 공에 비중을 둡니다.
- **로고·글자**: 골프존 로고나 화면 글자는 뭉개져 나옵니다. 매장과 스크린은 로고 없는 일반 스크린골프장으로 만들고, 서비스 이름은 자막과 로고 그래픽으로만 보여 줍니다.
- **폰 화면 내용**: 폰 화면은 "밝게 빛나는 빈 화면(blank glowing screen)"으로 만들고, 실제 앱 화면은 편집에서 넣습니다.

모든 프롬프트 끝에 붙입니다.

cinematic commercial look, warm indoor lighting, shallow depth of field, smooth slow camera movement, photorealistic, 16:9, no text, no logos
