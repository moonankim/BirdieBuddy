# BirdieBuddy 디자인 시스템 초안

달리기 앱 레퍼런스의 밝은 민트 배경, 짙은 그린 버튼, 둥근 카드와 하단 내비게이션을 골프 카드 수집 서비스에 맞게 해석했다. 이 문서와 HTML은 시각적 초안이며 제품 동작을 구현한 앱이 아니다.

## 사용법

- `foundation.html`: 컬러·서체·간격·모서리·적용 예를 한 장으로 정리한 파운데이션
- `index.html`: 컬러·서체·아토믹 컴포넌트 갤러리
- `sample/index.html`: 모바일 홈
- `sample/collection.html`: 컬렉션과 보유 카드
- `sample/chat.html`: 채팅방
- `styles.css`: 세 화면과 갤러리에서 공유하는 토큰 및 컴포넌트

파일을 브라우저에서 직접 열 수 있다. 화면 안의 데이터는 기획 검토용 가상 데이터다. 계정·라운드·카드·메시지의 저장이나 서버 연동은 없다.

## 컬러

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `--pine-950` | `#10231e` | 진한 본문·내비게이션 |
| `--pine-800` | `#183e32` | 기본 버튼·강조 |
| `--green-500` | `#438663` | 활성 표시·게이지 |
| `--mint-100` | `#d2e1d6` | 카드·강조 배경 |
| `--mint-50` | `#edf2ed` | 페이지 배경 |
| `--surface` | `#ffffff` | 카드·입력 영역 |
| `--ink-muted` | `#5c6c62` | 보조 텍스트 |
| `--border` | `#d3ded5` | 구분선·입력 테두리 |
| `--special` | `#ae8950` | 스페셜 등급 |
| `--danger` | `#a84c4d` | 오류·차단 |

색상만으로 등급이나 상태를 구분하지 않고 텍스트를 함께 쓴다. 값과 접근성은 실제 제품 적용 전에 검토한다.

## 서체와 간격

서체는 `Noto Sans KR`, `Apple SD Gothic Neo`, `Malgun Gothic`, 시스템 sans-serif 순서로 사용한다. Noto Sans KR은 Google Fonts에서 불러오며 네트워크를 사용할 수 없으면 대체 서체가 표시된다. 기본 본문 16px, 보조 12px, 제목 20~32px, 숫자·영문에는 같은 계열을 사용한다. 기본 간격은 4px 단위이며 4·8·12·16·20·24·32·40·48px을 공통 토큰으로 사용한다. 공통 서체 크기와 간격, 모서리 값은 `styles.css`의 CSS 변수로 관리한다.

## Atomic 구성

| 단계 | 초안 구성 | 사용 예 |
| --- | --- | --- |
| Atom | 버튼, 아이콘 버튼, 배지, 입력, 아바타, 게이지 | `.button`, `.badge`, `.avatar`, `.progress` |
| Molecule | 카드 타일, 검색창, 섹션 헤더, 채팅 말풍선 | `.card-tile`, `.search`, `.section-head`, `.bubble` |
| Organism | 앱 헤더, 카드 그리드, 채팅 대화, 하단 내비게이션 | `.app-header`, `.card-grid`, `.messages`, `.bottom-nav` |
| Template | 모바일 화면 셸과 공통 여백 | `.phone`, `.content`, `.page-title` |
| Page | 홈·컬렉션·채팅 | `sample/` |

실제 앱에서는 이 CSS 토큰을 기존 프론트 셋업과 합의해 옮기고 공통 UI를 재사용 가능한 컴포넌트로 구현한다. 화면별 목업을 복제해 별도 디자인 기준으로 사용하지 않는다.

## 제품 기준

- 컬렉션은 미보유 템플릿도 포함하고, 보유 카드 탭은 1장 이상만 보여준다.
- 등급은 일반·레어·에픽·스페셜이다. 강화는 같은 카드 10장이 초기 기준이다.
- 채팅방에서 팬은 본인 질문과 인플루언서 답변을 본다. 답변에 인용되는 다른 팬의 질문은 익명으로 표시한다.
- 카드 발급과 강화의 확정·권한 판정은 서버 책임이다. 이 시안은 추첨·저장·메시지 전송을 실행하지 않는다.
- 실제 인플루언서 사진 대신 가상 인물을 나타내는 그래픽 자리표시자를 사용했다. 최종 아트는 인물 10명 × 스타일 3종으로 별도 제작한다.

## 검토 사항

레퍼런스는 영문 중심이므로 한글 폰트의 크기·행간과 색상 대비를 실제 화면에서 확인해야 한다. 시안의 인물 이름·카드 아트·수량은 확정 데이터가 아니다. 원본의 상거래·신발 UI는 가져오지 않고 시각적 방향만 참고했다.

## 개선 적용 기준 (0.2)

- 색상 원형은 유지하고 text-primary/secondary/accent, surface-screen/raised/subtle, action-primary/hover/pressed, border-input, focus-ring 등 의미 토큰으로 연결했다.
- 모바일 본문·입력 16px, 보조 정보 최소 12px, 제목 자간 -0.025em을 기준으로 한다.
- 필터·탭·날짜는 텍스트 대비가 충분한 역할 색상을 사용한다. Green 500은 작은 글자 대신 진행 표시 등에 사용한다.
- 버튼·필터·탭·아이콘 버튼은 44px 이상 조작 영역을 제공한다. 반응형 목록은 줄바꿈하며 입력 영역은 축소 가능하다.
- 문자·이모지 구조 아이콘을 같은 24px 좌표계·1.75 선 굵기의 인라인 SVG로 교체했다. 아이콘은 장식으로 숨기고 조작 이름은 링크 텍스트·aria-label에서 제공한다.
- 버튼의 hover/pressed/focus/disabled/loading과 입력의 default/focus/disabled/error 스타일을 공유한다. 파운데이션에서 상태 예시를 확인한다.
- CSS와 HTML을 읽기 쉬운 줄 단위로 정리했다. 도형 자리표시자의 피부색·이미지 표현도 공통 원형 토큰으로 관리한다.
- 현재 라이트 테마만 정의한다. 이미지 생성·서버 연동·다크 테마 확장은 포함하지 않는다.
- 조작 피드백은 120ms이며 prefers-reduced-motion에서는 애니메이션과 전환을 생략한다.
