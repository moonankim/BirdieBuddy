# BirdieBuddy 디자인 시스템 초안

> **실제 카드 이미지 인계:** [R2 CDN 주소·DB/프론트 적용 지침](../docs/card-assets.md), [36개 이미지 JSON 목록](../docs/assets/card-images.json)을 사용합니다. 선수 식별자 12개·3등급이며 최종 이미지는 R2 출처입니다. 기존 Supabase Storage URL 생성·스타일 기반 경로를 그대로 적용하지 않습니다. DB·SDK·화면 연결은 아직 별도 작업입니다.

> **디자인 시스템 적용 인계:** 화면·공통 UI 작업 전 [에이전트 적용 가이드](./AGENT_GUIDE.md)를 확인합니다. 최신 원본·적용 상태·샘플 전용 구성·담당 경계와 검증 기준을 정리했습니다. 실제 API 연결을 보존하고 이전 카드 정의를 신규 요구사항으로 복제하지 않습니다.

> **최신 카드 기준:** 스타일 없음 / `kpga·klpga·gtour·media` / `basic·rare·legend`. 최종 카드 path는 `<유형>-<선수명>-<레벨>.png`이며 레벨은 등급과 같습니다. [공통 변경 명세](../docs/card-spec.md)를 우선합니다. 아래 이전 등급·스타일 예시와 실제 UI 타입은 전환 전 상태이며 신규 계약으로 복제하지 않습니다.

공태풍 G투어 카드 레퍼런스의 딥그린·아이보리·굵은 스포츠 타이포를 골프 카드 수집 서비스 전반에 적용했다. 카드가 시각적 중심이 되고 앱은 절제된 프레임 역할을 한다. 이 문서와 HTML은 시각적 초안이며 제품 동작을 구현한 앱이 아니다.

앱 전반의 적용 기준과 화면별 상태는 [앱 디자인 가이드](../docs/design.md)를 따른다. 카드 디자인은 별도 프로젝트에서 진행하며 기본 비율은 2:3이다. 뽑기 연출은 미정이다.

## 사용법

실제 앱 개발에는 [개발 적용 가이드](./DEVELOPMENT.md)의 `tokens.css`, `app.css`, 아이콘 에셋과 React 구성요소를 사용한다. 토큰과 앱용 스타일은 프론트에서 직접 import하며 컬렉션에 카드·빈 상태 구성요소를 적용했다.

- `foundation.html`: 컬러·서체·간격·모서리·적용 예를 한 장으로 정리한 파운데이션
- `index.html`: 컬러·서체·아토믹 컴포넌트 갤러리
- `sample/index.html`: 모바일 홈
- `sample/collection.html`: 컬렉션과 보유 카드
- `sample/chat.html`: 채팅방
- `sample/states.html`: 로딩 스피너·화면 로딩·연결 오류·404·기본 프로필 크기별 정적 샘플
- `states.css`: 앱과 시안이 공유하는 스피너·상태 화면·프로필 표시 스타일
- `../public/assets/avatar-default.svg`: 기본 프로필 공통 원본. 앱 URL은 `/assets/avatar-default.svg`
- `assets/connection-error.svg`: 연결 오류 샘플용 골프 깃발 일러스트
- `sample/screens.html`: 발급 결과, 강화 확인, 인박스와 설정·오류·빈 상태
- `assets/card-placeholder.svg`: 앱 화면용 2:3 카드 자리표시자. 최종 카드 디자인이 아니다.
- `styles.css`: 화면과 갤러리에서 공유하는 토큰 및 컴포넌트

파일을 브라우저에서 직접 열 수 있다. 화면 안의 데이터는 기획 검토용 가상 데이터다. 계정·라운드·카드·메시지의 저장이나 서버 연동은 없다.

추가 화면의 버튼은 실제 작업을 수행하지 않으며, 인박스의 원래 질문 펼치기는 시각적 상태 확인용이다. 발급 결과는 서버에서 확정된 결과의 예시이고 뽑기 연출은 포함하지 않는다. 카드 표시 영역은 2:3을 사용한다. `sample-` 클래스는 시안용이며 실제 앱은 `app.css`의 `bb-` 구성요소를 사용한다.

## 서체와 간격

서체는 `Noto Sans KR`, `Apple SD Gothic Neo`, `Malgun Gothic`, 시스템 sans-serif 순서로 사용한다. Noto Sans KR은 Google Fonts에서 불러오며 네트워크를 사용할 수 없으면 대체 서체가 표시된다. 기본 본문 16px, 보조 12px, 제목 20~32px, 숫자·영문에는 같은 계열을 사용한다. 기본 간격은 4px 단위이며 4·8·12·16·20·24·32·40·48px을 공통 토큰으로 사용한다. 공통 서체 크기와 간격, 모서리 값은 `tokens.css`의 CSS 변수로 관리한다.

## Atomic 구성

| 단계 | 초안 구성 | 사용 예 |
| --- | --- | --- |
| Atom | 버튼, 아이콘 버튼, 배지, 입력, 아바타, 게이지 | `.button`, `.badge`, `.avatar`, `.progress` |
| Molecule | 카드 타일, 검색창, 섹션 헤더, 채팅 말풍선 | `.card-tile`, `.search`, `.section-head`, `.bubble` |
| Organism | 앱 헤더, 카드 그리드, 채팅 대화, 하단 내비게이션 | `.app-header`, `.card-grid`, `.messages`, `.bottom-nav` |
| Template | 모바일 화면 셸과 공통 여백 | `.phone`, `.content`, `.page-title` |
| Page | 홈·컬렉션·채팅 | `sample/` |

실제 앱에서는 이 CSS 토큰을 기존 프론트 셋업과 합의해 옮기고 공통 UI를 재사용 가능한 컴포넌트로 구현한다. 화면별 목업을 복제해 별도 디자인 기준으로 사용하지 않는다.

## 제품 기준

- 컬렉션은 미보유 템플릿도 포함하고, 보유 카드 탭은 1장 이상만 보여준다.
- 등급은 일반·레어·에픽·스페셜이다. 강화는 같은 카드 10장이 초기 기준이다.
- 채팅방에서 팬은 본인 질문과 인플루언서 답변을 본다. 답변에 인용되는 다른 팬의 질문은 익명으로 표시한다.
- 카드 발급과 강화의 확정·권한 판정은 서버 책임이다. 이 시안은 추첨·저장·메시지 전송을 실행하지 않는다.
- 실제 인플루언서 사진 대신 가상 인물을 나타내는 그래픽 자리표시자를 사용했다. 최종 아트는 인물 10명 × 스타일 3종으로 별도 제작한다.

## 검토 사항

레퍼런스는 영문 중심이므로 한글 폰트의 크기·행간과 색상 대비를 실제 화면에서 확인해야 한다. 시안의 인물 이름·카드 아트·수량은 확정 데이터가 아니다. 원본의 상거래·신발 UI는 가져오지 않고 시각적 방향만 참고했다.

## 공통 사용성 기준

- 색상 원형은 유지하고 text-primary/secondary/accent, surface-screen/raised/subtle, action-primary/hover/pressed, border-input, focus-ring 등 의미 토큰으로 연결했다.
- 모바일 본문·입력 16px, 보조 정보 최소 12px, 제목 자간 -0.025em을 기준으로 한다.
- 필터·탭·날짜는 텍스트 대비가 충분한 역할 색상을 사용한다. Green 500은 작은 글자 대신 진행 표시 등에 사용한다.
- 버튼·필터·탭·아이콘 버튼은 44px 이상 조작 영역을 제공한다. 반응형 목록은 줄바꿈하며 입력 영역은 축소 가능하다.
- 문자·이모지 구조 아이콘을 같은 24px 좌표계·1.75 선 굵기의 인라인 SVG로 교체했다. 아이콘은 장식으로 숨기고 조작 이름은 링크 텍스트·aria-label에서 제공한다.
- 버튼의 hover/pressed/focus/disabled/loading과 입력의 default/focus/disabled/error 스타일을 공유한다. 파운데이션에서 상태 예시를 확인한다.
- CSS와 HTML을 읽기 쉬운 줄 단위로 정리했다. 도형 자리표시자의 피부색·이미지 표현도 공통 원형 토큰으로 관리한다.
- 현재 라이트 테마만 정의한다. 이미지 생성·서버 연동·다크 테마 확장은 포함하지 않는다.
- 조작 피드백은 120ms이며 prefers-reduced-motion에서는 애니메이션과 전환을 생략한다.

## 카드 중심 컨셉 (0.3)

- 화면은 아이보리, 버튼은 딥그린, 본문은 잉크그린을 사용한다. 골드는 등급과 수집 성취에 한정한다. 기존 `mint` 토큰 이름은 호환을 위해 유지하되 세이지·아이보리 값으로 변경했다.
- 모서리는 조작 6px, 패널 12px, 주요 배너 20px, 카드 16px이다. 주요 제목은 28px·800, 본문 16px, 보조 12px을 사용한다. 영문 디스플레이에는 Arial Narrow를 우선하고 한글은 Noto Sans KR을 사용한다.
- `club.css`는 앱·정적 시안의 카드 중심 배너와 카드 표시 규칙을 공유한다. 사선은 배너 배경에만 적용하고 본문과 조작 영역은 기울이지 않는다.
- 홈에 사용자 제공 공태풍 카드를 디자인 미리보기로 표시한다. 원본은 `public/cards/gong-tae-pung-basic.png`이며 실제 소유·발급 데이터와 연결하지 않는다. 다른 인물에는 이 사진을 사용하지 않는다.
- 앱의 공통 CardArtwork는 2:3 원본을 자르지 않고 표시하며 등급을 이미지 밖에 둔다. 정적 기존 카드 타일은 자리표시자 예시다. BASIC·RARE·LEGEND 표기는 레퍼런스 아트에 포함된 것으로 서비스의 일반·레어·에픽·스페셜을 변경하지 않는다.
- 하단 탐색은 아이보리 표면과 그린 활성 표시·밑줄을 사용한다. 채팅·입력·오류 상태는 공통 의미 토큰을 따른다.

## 전시와 깊이 보강 (0.4)

- 대표 카드의 가로 공간을 확대하고 약한 기울기와 두 단계 그림자로 홈의 시각적 중심을 만든다. 카드를 누르면 컬렉션으로 이동하며 호버·누름 반응은 동작 줄이기를 존중한다. 카드 상세 화면 전환은 구현하지 않는다.
- 배너의 코스 등고선은 로컬 SVG 배경으로 사용한다. 은은한 빛과 사선 면을 겹치되 콘텐츠와 원본 카드에는 질감을 덮지 않는다.
- 홈의 라운드 패널과 컬렉션의 수집 현황에 밝은 표면·그린 상단 선·얕은 그림자를 적용한다. 수집 수치는 40px로 강조하고 컬렉션 카드에는 짧은 그림자와 메타정보 구분선을 둔다. 미보유 카드는 그림자를 제외한다.
- `shadow-panel`, `shadow-card`, `motion-card`를 공통 토큰으로 사용한다. 반복 애니메이션과 질감 표현은 추가하지 않고 채팅·설정의 표면 스타일은 유지한다.

## 공통 상태 샘플

로딩·오류 화면은 `sample/states.html`에서 검토한다. 재시도 버튼은 정적 샘플에서 비활성화하며 실제 요청을 실행하지 않는다. 홈 이동 링크는 정적 홈 시안으로 연결된다. 스피너에는 항상 읽을 수 있는 안내를 함께 제공하고, 동작 줄이기 설정에서는 회전을 멈춘다.

기본 프로필은 아이보리 원형 프레임과 딥그린 실루엣으로 구성한 단일 SVG다. 채팅 메시지 32px, 목록 44px, 설정 72px을 사용한다. 실제 앱의 Avatar는 아직 이름 첫 글자 대체 방식을 유지하며 새 에셋 연결은 후속 적용 사항이다. Next.js 오류·404 라우트도 이번 샘플에는 포함하지 않는다.
