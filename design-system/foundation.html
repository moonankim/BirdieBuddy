공유 규칙

색상은 역할로, 상태는 동작으로

원색 값은 공통 토큰에서 관리하고 화면에서는 의미 토큰을 사용해.

일반 텍스트 text-primary / surface-screen 본문·제목 · 대비 14.46:1
보조 텍스트 text-secondary / surface-raised 필터·날짜·설명 · 대비 5.56:1
기본 동작 text-inverse / action-primary 기본 버튼 · 대비 11.84:1

일반 텍스트는 4.5:1 이상을 기준으로 해. Green 500은 게이지 등 시각 표시용이며 작은 글자에는 text-accent를 사용해.

버튼 상태

키보드 Tab으로 초점 표시를 확인해. Focus는 3px 외곽선, 조작 영역은 최소 44px이야.

입력 상태

이름을 입력해 주세요.

모션은 상태 피드백 120ms부터 시작하고, 동작 줄이기 설정에서는 전환·회전을 생략해. 라이트 테마 초안이며 다크 테마는 별도 검토가 필요해.

읽음 상태

어디까지 읽었는지 한눈에

"여기까지 읽었어요" 기능의 구분선·안 읽은 수·NEW·최신 이동을 같은 딥그린 체계로 표시해. 색만으로 전달하지 않고 항상 글자를 함께 써.

읽은 위치 구분선

  • 여기까지 읽었어요

첫 안 읽은 메시지 바로 위에 한 번만 둬. 채팅방을 처음 열 때 위치를 정하고, 새 메시지가 와도 움직이지 않아. .bb-read-divider

안 읽은 수 · NEW

1 12 99+ NEW

숫자는 채운 배지, NEW는 테두리 배지로 구분해. 0이나 값 없음이면 배지를 그리지 않아. 보유 배지(버디 등)와 섞어 쓰지 않아. .bb-count-badge .bb-new-badge

최신 메시지로 이동

맨 아래가 아닐 때만 목록 하단에 떠 있어. 누르면 최신 메시지로 이동하고 사라져. 새 메시지 수는 선택 사항이야. .bb-jump-latest
